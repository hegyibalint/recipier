# Recipier (frontend)

- TypeScript as the main language
- Remix as the main framework, using React 18
- Tailwind CSS for styling
- React Query for data fetching, based on an OpenAPI spec
- Vitest with browser mode for testing

## Programming style
- Don't destruct props in functional components.

## Styling
The application is in a prototype stage, and no styling should be applied.
Strife on functionality, the application can be as ugly.
