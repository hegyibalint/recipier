# Recipier

The application is an ingredient/recipe management software.
The software consists of two main component:
 - A Java backend in `recipier-backend`
 - A Remix-based frontend in `recipier-frontend`

## API
The OpenAPI specification is located in `recipier-backend/build/openapi.json`. If it doesn't exist, can be generated with `gradlew generateOpenApiDocs` (`gradlew` is located in the project root).

The OpenAPI schema is generated by `openapi-typescript`. 
The generated file is located in `recipier-frontend/src/api/schema.ts` file.
If the file doesn't exist, it can be generated with `npm run openapi:generate`.

## Testing
Frontend testing uses Vitest with browser mode (Playwright) and React testing utilities:
- Test files: `*.test.{ts,tsx}` 
- Run tests: `npm test`
- Watch mode: `npm run test:watch`
- Testing library: `vitest-browser-react` for rendering and `@vitest/browser/context` for user events
- Environment: jsdom with browser mode enabled using Chromium
- Import pattern: `import { render, screen } from "vitest-browser-react"` and `import { userEvent } from "@vitest/browser/context"`
